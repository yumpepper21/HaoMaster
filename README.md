# 郝大师 (HaoMaster) 🐶🔍

**“告别全家桶，你的下一款硬件检测工具，何必是鲁大师。”**

欢迎来到 **郝大师** —— 一款专治各种流氓软件不服的纯本地硬件检测工具。

受够了开机弹窗？受够了跑分造假？受够了所谓的“一键体检”疯狂往你电脑里塞全家桶？
我决定自己动手，用 C# 打造一把极简、纯粹、暴力的“硬件手术刀”。

---

## ✨ 核心特性（专治各种不服）

*   **⚡ 1.4秒极速穿透**：底层多线程并发读取，仅需 1.4 秒，瞬间抓取 **12 个分类、127 项** 真实硬件数据。
*   **🛡️ 绝对纯净，拒绝流氓**：单文件绿色版，解压即用，甚至不需要安装。没有广告，没有弹窗，没有后台常驻。
*   **🔍 扒光底裤的颗粒度**：
    *   **CPU**：架构、核心数、三级缓存、实时频率甚至 CPU ID。
    *   **内存**：不只看容量，连内存条的制造商（如海力士）、型号、真实频率全给你扒出来。
    *   **显卡**：完美识别核显+独显双阵容，支持读取显存大小、驱动版本、PNP ID。
    *   **硬盘**：精准定位 SSD 型号（如铠侠 KIOXIA）、接口协议，以及 C/D/E 盘的真实剩余空间。
    *   **主板/BIOS**：精确到 BIOS 的发布日期、序列号以及主板型号。
*   **🛠️ 管理员权限提权**：为了保证读出来的数据 100% 真实，软件会自动申请管理员权限（调用底层 WMI 接口），绝不弄虚作假。

## ⚠️ 重要注意事项（必看！）

1.  **杀毒软件误报 (False Positives)**：
    由于本软件是个人开发者使用 C# 编译，**未购买商业数字签名**，且需要调用底层接口，Windows Defender 或某某卫士可能会报毒拦截。**请放心点击“更多信息” -> “仍要运行”**。
2.  **管理员权限**：软件启动时，请在弹出的 UAC 窗口中点击“是”，否则部分底层硬件数据（尤其是主板和深层传感器）无法读取。
3.  **解压使用**：请前往 **Releases** 页面下载 `.7z` 压缩包，使用 7-Zip 解压后双击运行。
